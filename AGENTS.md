# About

This is a repository for a low-poly 3D horror game that uses the SmartSpectraSDK by Presage Technologies to loop in siginals based on facial detection into gameplay.

The game is called "Granny is Watching". The theme of the setting and the main horror entity (grandma) is traditional Indonesian in a very rural area.

## Gameplay documentation

When changing player-facing gameplay, progression, or endings, update `docs/core-game.md` in the same patch.

When changing congklak gameplay, update `docs/congklak-rules.md` in the same patch. Check the setup, turn rules, controls, examples, and scoring against `src/congklak.js` and the behavior players see in the game.
