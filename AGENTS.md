# About

This is a repository for a low-poly 3D horror game that uses the SmartSpectraSDK by Presage Technologies to loop in siginals based on facial detection into gameplay.

The game is called "Granny is Watching". The theme of the setting and the main horror entity (grandma) is traditional Indonesian in a very rural area.
